# 0.10 验证记录

键盘控制区的「收起」替换为 Win，使用底部或侧边工具栏的键盘图标展开、收起。Win 在 Android 中对应 Meta 修饰键，与 Ctrl / Alt / Shift 一样支持一次性修饰和长按锁定，关闭键盘、旋转本机或断开时清除。发送组合键时实际按下 Meta 左键，再发送目标键，最后按相反顺序释放，避免远端修饰键残留。

齿轮弹窗顶部新增「向左旋转」「向右旋转」，每次将远端实际方向调整 90°。弹窗背景半透明，降低背景遮暗，旋转后无需关闭弹窗即可观察画面。手动方向仅在本次会话生效；启用方向同步时，下一次转动本机会重新跟随，关闭同步时本机转动不影响手动方向。断开后恢复会话开始前的方向和自动旋转设置。仅观看模式禁用两个按钮。

## 构建

JDK 11、Android SDK 31，离线构建应用和验证 APK，20 项 JVM 测试及 app lint 通过。新增测试验证 Win 的一次性、锁定和清除行为，以及 Ctrl + Win 组合键的按下和释放顺序。

## 双 AVD 验证

使用两个专用 Android 14 AVD，实际 ADB TCP 连接。`scripts/verify-avd.py --phase manual-rotation` 读取远端系统方向设置及输入系统报告的实际显示方向，检查左右 90°、四个方向和快速连点；本机保持竖屏，视频进程保持原 PID。亮色验证画面用于检查弹窗透明效果，截图保存在仓库外。

手动方向的连续旋转基于上一次请求角度计算，避免系统旋转动画未完成时快速点击丢失步数。查询当前方向的子 shell 清除继承的退出处理，避免查询命令提前恢复设置或删除会话文件。

Win 的系统快捷键与清理补充专项使用 `--phase manual-rotation-controls`。实际 Win+H 能返回远端桌面，长按锁定后可连续使用；收起后重新展开，普通 H/J 输入的 Meta 状态为零。Android 14 将 Meta 组合键保留给系统处理，因此验收观察实际系统动作；依据为 [Android 按键策略](https://android.googlesource.com/platform/frameworks/base/+/android-14.0.0_r1/services/core/java/com/android/server/policy/PhoneWindowManager.java)。

仅观看模式的两个旋转按钮均禁用，远端设置不变。手动旋转后，正常断开与强制停止客户端两种情况下，远端原方向和自动旋转开关均恢复。
