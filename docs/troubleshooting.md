# 排障指南

[文档索引](README.md) · [使用说明](usage.md) · [验证指南](testing.md)

先区分主控应用、远端 adbd、视频 / 声音服务和本机验证环境。保留错误文案与当次日志，按下表定位；不要先清空配置或卸载应用。

| 现象 | 检查顺序与依据 |
| --- | --- |
| 网络连接超时 | 主机 / 端口是否分开填写；两端是否能互访；目标是否开启传统 ADB TCP；防火墙 / 代理是否干扰。配对码 / TLS 无线调试暂不支持 |
| 一直等待授权 | 远端解锁，确认调试授权；客户端使用自己的 RSA 密钥，主机 adb 已授权不能代替应用授权。清数据会生成新密钥 |
| USB 列表为空 | 数据线是否传数据、主控是否 Host / OTG、远端 USB 调试是否打开、ADB 接口是否枚举。点击设备列表刷新 |
| USB 能列出但不能连接 | 分别确认本机 USB 访问与远端 ADB 授权；检查主从角色、接口占用和是否拔插。USB 不会自动回退 TCP |
| 有连接但无画面 / 解码失败 | 尝试 H.264、较低最长边 / 码率；查看 `ScrcpyServer` 的编码器信息与 `ScrcpySession` 的帧 / 解码错误 |
| 触控 / 按键无效 | 先检查仅观看；检查画面尺寸与触控坐标映射、控制队列和远端输入焦点。用探针确认实际接收事件 |
| 上下滑触发本机系统栏 / Home | 起点是否在物理系统保留区域；改从远控画面边缘滑入。普通应用不能完全禁用本机强制手势 |
| 远端不跟随方向 | 检查同步开关、仅观看、远端应用是否锁定方向；用手动旋转区分本机布局与远端旋转能力，查看 `RemoteSettings` |
| 远端声音小或无声 | 播放开关、远端 Android 版本 / 解锁、本机与远端媒体音量；检查路由是否刚切换。`output` 转发时远端扬声器静音属于预期 |
| 麦克风无输入 | 转发开关默认关闭；检查本机录音权限、仅观看和远端 shell 音频路由支持。厂商可能限制能力；看 `ScrcpyAudio` 中的 MIC 日志 |
| 配置或语言切换后丢值 | 区分未保存表单与持久化配置，检查 `Profile` 缺省读取、临时 USB 设备名及表单语言重建流程，参照配置专项 |
| APK 无法覆盖安装 | 核对包名、versionCode 和证书；换构建机可能使用另一份 debug keystore，见发布指南，不默认卸载 |
| 新 worktree 离线构建失败 | 检查 JDK 11、SDK、Gradle 缓存和该 worktree 的 server 文件；`--offline` 不禁止下载脚本联网 |
| AVD 之间的原始 TCP 不通 | 检查目标 adbd TCP、宿主机转发、客户端 `10.0.2.2` 路径；用启动脚本排除继承宿主机代理的问题 |
| 自动化控件缺失 / 操作错位 | 确认专用设备归属、方向、屏幕规格、系统弹窗与当前语言。不要并发跑 UI 专项；核对稳定资源 ID 与新入口 |

## 日志与源码入口

对明确属于本任务的设备读取日志；替换序列号占位符：

```bash
adb -s '<client-serial>' logcat -d \
  -s ScrcpySession ScrcpyServer ScrcpyAudio RemoteSettings RemoteGesture
```

| 标签 | 对应区域 |
| --- | --- |
| `ScrcpySession` | ADB 建连、视频读取 / 解码、会话失败 |
| `ScrcpyServer` | 官方远端视频服务输出 |
| `ScrcpyAudio` | 本机播放与麦克风启动、停止或失败；声音服务输出也可能附在错误中 |
| `RemoteSettings` | 设置命令回执与恢复相关状态 |
| `RemoteGesture` | 边缘动作、取消触控、本机 Back 转发 |

更多类职责见 [架构地图](architecture.md)。日志、截图可能包含设备名和网络信息，保存在仓库外；文档仅记录脱敏结论。

## 验证中断后的恢复

确认当前设备在线和所属任务，查看测试退出状态、`result.json`、失败截图与日志。先修复设备 / 环境或实现的根因，再按 [阶段索引](testing.md) 补跑受影响范围；保留中断与补跑两段证据。

设备内核崩溃不能仅凭时间相关就归因于应用。历史上曾因另一会话在目标机尝试提权而中断，见 [0.1 记录](validation/0.1.md)。当前故障仍需本轮独立证据，避免同时在同一设备进行高干扰操作。

不要用广泛进程匹配结束远端服务，也不重置其他会话的旋转、音量、AVD 或 adb server。只能按当前任务归属清理残留，并明确哪些状态尚未恢复。
