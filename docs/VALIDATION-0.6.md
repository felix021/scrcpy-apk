# 0.6.0 验证记录

验证日期：2026-11-07。APK SHA-256：`08efb7ce4eb844abd07c158ed650fba8c91e9df04e7791786c34ad687d458d67`。

## 界面

保存连接配置、输入文字两个弹框改用与切换配置、删除和断开确认相同的深色圆角样式。输入框使用统一配色，空名称和超限文本直接在弹框内显示错误；修改输入后清除提示。视频编码菜单也提供同色选项、勾选标记和选中背景。

输入弹框的内容区可以滚动，底部按钮独立固定。弹框窗口使用内容自适应尺寸，内部按可用高度测量，避免横屏系统键盘遮挡保存、发送及取消按钮。退出远控时清理输入弹框，旧弹框不会向后续连接发送内容。

连接状态在左侧最多显示三行，字号按空间自动调整，长按可查看完整文字。三枚主要导航键独立对齐屏幕中线，横屏时补偿左右安全区的不对称；两侧内容不能挤动导航位置。

## 验证

使用两个 Android 14 AVD，通过真实 ADB TCP 和官方 scrcpy server 验收，保存与导航专项、文字输入专项及后台清理检查分别完成：

- 空名称不写入配置，取消保存保留原数据；横竖屏系统键盘打开时可以保存，底部按钮未被遮挡。
- 编码菜单可在 H.264 / H.265 之间切换，选中状态正确。
- 竖屏、320 dp 窄屏、带单侧挖孔的横屏及横屏展开虚拟键盘时，Home 和三键整体中心均与窗口中点相差不超过 2 像素。状态与右侧按钮无重叠。
- 取消文字输入不发送；超过 64 KB 的文本保留在本机并提示错误；中文和 emoji 实际到达远端输入框。
- 横屏文字弹框的按钮位于系统键盘之上，取消后会话继续。离开客户端后输入弹框和远端服务均清理，返回时没有旧弹框。

后台检查等待客户端实际回到桌面且远端服务退出后再打开客户端。超限输入由测试文件传入，避免 ADB 命令长度影响结果；测试辅助进程在完成操作后明确结束，避免退出时的无障碍回调竞争。

JDK 11 构建、17 项 JVM 测试通过，Android lint 无错误。测试图片、输入文件及日志保存在仓库之外。
