# 0.8 验证记录

使用两个专用 Android 14 AVD，一台运行客户端，一台作为实际 ADB TCP 远端。APK、截图和日志保存在仓库外。

## 构建

JDK 11、Android SDK 31，离线运行 `:app:assembleDebug :app:testDebugUnitTest :app:lintDebug`，17 项 JVM 测试通过，lint 无错误。沿用上一版签名，可覆盖升级。

## 运行时设置

齿轮弹窗包含虚拟导航键、完整键盘、声音播放、麦克风转发、充电时保持唤醒、方向同步和界面语言；断开连接仍需再次确认。地址、画质和仅观看模式需要在连接前选择。

方向同步默认开启，旧配置缺少该字段时保持上一版行为；每台主机分别保存。关闭同步或保持唤醒时立即恢复会话开始前的对应设置。两个设置由同一个远端 shell 管理，正常退出和 ADB 断开都会恢复，只恢复本次会话实际改动的字段。

`--phase runtime` 通过：连接前关闭同步，本机转横屏不影响远端；连接后分别开关同步和保持唤醒，检查远端三项系统设置的实际值，同时确认视频进程没有替换。隐藏后再展示三键时保持屏幕中线，状态文字区域与按键无重叠；完整键盘可立即展开和收起。断开确认取消后保留连接。运行时开关写回当前已保存主机，画面参数保持不变。

声音服务与视频服务分开运行，关闭播放会结束远端系统声音采集及本机播放，再次开启可重启声音服务。关闭麦克风会停止本机录音、发送结束帧并等待远端撤销音频路由。切换开关不重启视频。服务文件在会话内复用，断开时删除；远端视频和声音进程分别绑定各自的 ADB shell，关闭连接后不会因画面静止而残留。

`--phase audio-runtime` 在同一条视频连接中切换四种组合，用 997 Hz 注入本机录音输入，再由远端普通录音应用测量；远端同时播放 1499 Hz，由本机实际输出采集测量。数值为测试音的相关幅度：

| 播放远端声音 | 转发本机麦克风 | 本机输出 1499 Hz | 远端录音 997 Hz |
|---|---|---:|---:|
| 关闭 | 关闭 | 0 | 0 |
| 开启 | 关闭 | 288 | 0 |
| 关闭 | 开启 | 0 | 12016 |
| 开启 | 开启 | 287 | 12016 |

四种组合均通过，视频进程保持原 PID。两个开关关闭后，检查远端对应服务已经退出。连接期间开启麦克风才请求权限，拒绝后不启动录音、视频保持连接。测量前固定两端媒体音量，结束后恢复，避免模拟器重启后的音量差异影响结果。

## 语言与布局

中文和英文资源完整对应，默认跟随系统，其他系统语言回退英文。手动选择保存在客户端全局设置中；语言资源独立于 Activity，切换不会重建视频 Surface。

配置页标题和产品标识同排，画质档位合并到「画面与控制」右侧菜单。固定连接按钮上方的渐隐和文字提示表明还有设置，可点击或继续滑动，滚到底部后消失。远控设置沿用深色圆角弹窗；横屏时内容可滚动，底部操作按钮固定。

`--phase language` 验证跟随系统语言、标题同行、手动切换时保留未保存及无效输入、语言选择在进程重启后保留，以及画质菜单更新参数。临时缩短客户端屏幕后，检查滑动提示出现、点击滚动、滚到底隐藏，连接按钮位置不变。运行时语言切换可用 `--phase language-live` 单独补跑。

`--phase language-live` 通过：保持同一视频进程切换语言，设置弹窗、连接状态、完整键盘及其无障碍名称、文字 / 粘贴按钮和断开确认均更新；断开后配置页使用新语言。已检查中文竖屏、中文横屏和英文竖屏设置弹窗。
