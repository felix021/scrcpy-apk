# 0.5.0 验证记录

验证日期：2026-11-06。APK SHA-256：`dd26c3a958674e2c8707b857c2082504d8da4d8a8d606a3e1c2fce18fe6f76bd`。

本轮更新应用图标、断开按钮和连接配置弹窗。

## 图标

应用图标使用两台手机和手指触控的组合，背景采用深青色渐变，前景保持与应用一致的薄荷绿。使用 Android 自适应图标，支持不同桌面裁切；Android 13 及以上提供独立单色层，避免主题着色后手机轮廓互相穿透。图标均为矢量资源。

断开操作改为断开的插头图标，使用与导航键、键盘键相同的图标按钮，保留「断开连接」无障碍描述和长按提示。操作区在窄屏上自动缩小，保持按钮之间留有间距。手动点击断开图标会弹出同风格的二次确认，取消后连接继续；网络异常或离开远控页时会清理确认框，避免旧确认框影响后续连接。

## 配置弹窗

弹窗与主界面共享深色背景、圆角和薄荷绿配色，配置行显示名称和地址。选中的项目用边框、底色和勾选标记突出显示，另用「当前」区分正在使用的配置。

点选只改变高亮，点击「使用配置」才恢复设置。取消不改变当前配置。点击「删除」弹出第二次确认；取消删除保留列表和选择。确认删除后清除选中状态，避免连续误删。若删除正在使用的配置，仅清除它的名称，保留当前连接参数和其他主机的已保存数据。

配置列表可滚动，底部操作按钮固定；横竖屏变化后重新计算弹窗尺寸，并将选中的项目滚动到可见区域。

## 验证

JDK 11 构建、17 项 JVM 测试和 Android lint 通过。双 AVD 的界面专项通过以下检查：

- 点选只改变一个项目的高亮，取消保持原配置，确认才切换主机。
- 删除前需要第二次确认；取消删除保留选择；删除当前配置不会修改其他主机的数据。
- 旋转后仍能看见选中项目和底部操作区，测试配置清理后原有保存数据保持不变。
- 断开图标点击后需确认，取消保持真实远控会话；确认后远端服务退出。
- 桌面图标显示手机意象；键盘、断开使用相同图标按钮样式，在 320 dp 窄屏下不与居中导航重叠。
