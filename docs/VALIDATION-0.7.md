# 0.7 验证记录

使用两个专用 Android 14 AVD，一台运行客户端，一台通过真实 ADB TCP 连接作为远端。截图、日志、APK、SDK 配置均保存在仓库外。

## 构建

JDK 11，Android SDK 31，离线运行 `:app:assembleDebug :app:testDebugUnitTest :app:lintDebug :validation:probe:assembleDebug`。17 项 JVM 测试通过，lint 无错误。

## 横屏与摄像头

`--phase landscape` 验证：

- 客户端按横屏、竖屏、反向横屏、竖屏顺序切换，远端跟随；同一连接持续接收视频，稳定画面不会重复请求旋转。
- 横屏连接状态位于左侧，返回、Home、最近任务、键盘和断开图标在右侧竖排；竖屏恢复原有底栏，三键位于物理屏幕中线。
- 横屏触控区高度超过测试屏幕高度的 83%，顶部和底部仅保留系统安全区。
- 使用系统屏幕缺口模拟，分别检查左侧和右侧中央摄像头。断言状态文字及所有按钮的边界与系统报告的摄像头矩形无交集；上下圆角处保留空间。
- 展开键盘后与视频并排；双行控制区的 Up 位于 Left / Down / Right 上方，Home / End / PgUp / PgDn 均可直接使用。
- 断开确认选择取消后继续连接；仅观看模式不主动修改远端方向。

缺口模拟会修改 framework 资源并重建 Activity，因此先断开、切换模拟硬件、重新连接，再验证布局；测试结束恢复原有设备外形设置。

## 完整键盘

`--phase keyboard` 通过三键居中、Shift / Caps / Ctrl 一次性修饰及长按锁定、Alt、Fn 功能键、直接编辑导航键、中文与 6 KB 长文本粘贴、长按退格连续删除及松手停止、横屏并排键盘、两端同时横屏、隐藏导航后三键手势等检查。旋转期间保持同一连接，远端输入框继续接收字符。

## 旋转设置恢复

`--phase rotation` 验证开启自动旋转的远端：本机横竖屏切换时远端跟随；正常断开以及强制停止客户端后，远端自动旋转开关和原始方向均恢复。仅观看时两项设置保持原值。

Android 10+ 使用 WindowManager 的 `wm user-rotation lock` 一次提交方向与锁定状态；旧系统通过设置项更新。恢复动作由远端 shell 的退出处理负责，客户端异常结束也不依赖本机回调。初始化完成后才安装退出处理，避免初始化命令的子进程提前执行恢复。

## 双向声音

`--phase audio` 使用 997 Hz 模拟本机麦克风输入，远端测试应用以普通 `AudioRecord` 录音；同一测试应用同时播放 1499 Hz，客户端通过实际系统输出再次采集测量。测试会临时调整媒体音量，结束后恢复。下表数值是测试音的相关幅度：

| 播放远端声音 | 转发本机麦克风 | 本机输出 1499 Hz | 远端录音 997 Hz |
|---|---|---:|---:|
| 关闭 | 关闭 | 0 | 0 |
| 开启 | 关闭 | 287 | 0 |
| 关闭 | 开启 | 0 | 12016 |
| 开启 | 开启 | 288 | 12016 |

四种组合均通过。录音权限仅在开启麦克风后请求；拒绝后保留配置页，不启动录音。双向同时开启时，远端普通录音应用实际收到了本机 `AudioRecord` 经 ADB 转发的数据，同时本机输出收到远端的 AAC 解码声音。

断开后检查两端动态音频路由均为空，远端无残留麦克风服务进程或临时 APK。生产客户端在麦克风关闭时不创建 `AudioRecord`；测试中的本机模拟输入和系统输出测量由独立 shell 验证进程承担。

## 多主机配置

`--phase configs` 验证旧版保存数据的读取，以及两台主机的地址、端口、全部画面参数和全部开关独立恢复。两台主机分别保存相反的播放 / 麦克风开关组合，切换后均与保存值一致；旧数据缺少声音字段时，播放开启、麦克风关闭。同名更新、进程重启、删除取消、二次确认删除均通过；原有配置不丢失。竖屏和横屏都验证了顶部下滑只展开远端控制中心，本机系统栏保持隐藏。

## 本机系统手势

普通应用无法排除 Android 强制保留的底部 Home / 快速切换手势。沉浸模式也允许用户通过边缘滑动重新显示系统栏。本版本保留顶部状态栏高度及底部系统安全区；远端手势从画面边缘发起。

依据：[Android 手势兼容说明](https://developer.android.com/develop/ui/views/touch-and-input/gestures/gesturenav)。
