# 使用说明

[文档索引](README.md) · [排障指南](troubleshooting.md)

## 连接与配置

主控端运行本应用，需要 Android 8.0+。被控端开启开发者选项中的 USB 调试，支持所选视频编码；声音另有系统要求，见下文。

### 网络 ADB

1. 两端网络能够互访，在已获授权的电脑 adb 上对被控设备开启传统 TCP 调试，例如 `adb -s <target-serial> tcpip 5555`。
2. 配置页选择「网络 ADB」，填写被控端 IP / 主机名和端口；地址中不带协议前缀，端口单独填写。
3. 点击底部「连接设备」，首次在远端确认 ADB 调试授权。需要时勾选始终允许。

传统 ADB TCP 没有传输加密，应仅在可信网络使用。应用也支持下述无线调试 TLS 模式，连接时会根据远端 STLS 请求自动升级，无需另选传输类型。

### 无线调试配对（Android 11+ 被控端）

先在主控应用右上角「设置」填写「本机名称」，默认取系统设备名称，无法读取时使用机型。远端「已配对的设备」会显示此名称；Android 按空白切分名称，因此发送时把空白转为下划线，设置页会预览实际显示值。修改名称后，已存在的配对记录需在远端移除并重新配对才能更新。

1. 在被控端开发者选项开启「无线调试」，两端处于可互访的网络。
2. 主控应用选择「网络 ADB」→「无线调试配对」。二维码模式由主控展示二维码，被控端选择「使用二维码配对设备」后扫码；配对码模式则在被控端选择「使用配对码配对设备」，把地址、配对端口和六位码填写到主控。
3. 配对成功后，应用优先发现相同地址的连接端口；没有发现时，填写被控端「无线调试」主页面中的连接端口，然后点击「连接设备」。配对端口与连接端口不同，不能直接混用。
4. 配对后的网络会话使用 TLS 1.3，共用传统 TCP / USB 的持久化 RSA 身份。可以保存完整连接配置供下次使用；远端重新开启无线调试后端口可能变化。

二维码需要 mDNS（局域网设备发现）可用；跨网络或禁止组播时，使用配对码手工填写地址和两种端口。取消、刷新二维码或切换模式会关闭旧配对连接，配对秘密不保存到配置或日志。

### USB ADB

1. 主控手机支持并开启 USB Host / OTG；被控手机开启 USB 调试。
2. 使用支持数据传输的线连接两台手机，主控手机取得 Host 角色。
3. 选择「USB ADB」及设备，点击连接；依次批准主控手机的 USB 访问权限和被控手机的 ADB 调试授权。

USB 模式不需要填写 IP、端口或开启 ADB TCP。点击设备列表可重新扫描。拔线会结束会话，不会自动切换网络。USB 功能已由用户实机验收通过；开发侧证据范围见 [0.11 记录](validation/0.11.md)。

### 多设备与画质

「保存配置」保存名称、连接方式、主机地址 / USB 标识、画质和控制开关。同名保存会更新现有配置。通过「切换配置」选中条目、确认后切换；删除另有二次确认。USB 配置可以在插线前保存，连接时仍需选择实际接入的设备。

「画面与控制」右侧菜单提供省流、均衡、高清，也可自行修改最长边、码率、帧率和 H.264 / H.265 编码。配置页可滚动，底部连接按钮固定；底部渐隐和提示表示下方还有设置。默认值、档位参数及取值范围见 [配置说明](configuration.md)。

### 可选：跨网络连接

两端不在同一局域网时，可使用 EasyTier、Tailscale 等 SDN（软件定义网络）工具建立可互访网络，再填写组网地址。项目只依赖可访问的 ADB TCP 连接，不依赖某种组网软件或特定部署环境。

## 远控界面与手势

- 直接触控画面，支持单指与多指。本机 Back 事件转发到远端。
- 竖屏底部提供连接状态、居中的 Back / Home / 最近任务、键盘与设置。横屏状态放在左侧，操作按钮在右侧竖排，避开圆角和摄像头。
- 从远控画面左右边向内滑动为返回，底边向上为 Home，顶边向下打开控制中心；也能从画面旁的黑边滑入。动作不依赖远端使用手势还是三键导航。
- 「展示虚拟按键」默认开启，关闭后仍能使用边缘动作，完整键盘可单独展开。
- 齿轮打开半透明远控设置，可即时改变导航键、键盘、声音、麦克风、保持唤醒和方向同步。断开需要确认；切到后台会结束远控。

本机系统栏在远控时隐藏，顶部留出状态栏高度，底部避开系统保留区域。普通应用不能完全屏蔽系统强制手势；从物理屏幕最顶端 / 最底端滑动，仍可能触发本机系统栏或 Home。远端动作应从远控画面边缘开始。

## 完整虚拟键盘与文字

键盘图标负责展开、收起。布局参考 oh-my-term，只有 QWERTY：两行较扁的控制键、三行字母键、底部空格所在行。横屏时键盘在画面右侧。

| 操作 | 效果 |
| --- | --- |
| 点按字母 | 输入小写字母；Shift 生效时为大写 |
| 上滑字母键 | 输入键帽上方标注的数字 / 符号 |
| 下滑字母键 | 输入大写字母 |
| 点按 Ctrl / Alt / Shift / Win / Fn | 对下一个键生效 |
| 长按修饰键 | 锁定；再次点按取消 |
| 收起键盘、旋转本机或断开 | 清除修饰状态 |
| `123` / Shift | 打开数字符号面板 / 切换对应符号 |
| Fn + Q–P | F1–F10；F11 / F12 位于控制区 |
| Fn + Esc / Fn + Tab | Menu / Insert |
| 长按退格、回车、方向键 | 连续操作 |

键盘中的 Home 是编辑导航键，房子图标用于 Android 桌面；Win 对应 Android Meta 键，系统可能优先处理其组合键。

「文字」用本机输入法编辑后发送，支持中文等任意文字；「粘贴」仅在主动点击时读取本机剪贴板。这两项通过远端剪贴板粘贴，单次最多 64 KiB UTF-8，会覆盖远端剪贴板内容。

## 声音与麦克风

| 开关 | 方向 | 默认值 | 条件与行为 |
| --- | --- | --- | --- |
| 播放远端声音 | 远端系统声音 → 本机 | 开启 | 远端 Android 11+；AAC / 48 kHz / 双声道，Android 11 连接时需解锁 |
| 转发本机麦克风 | 本机麦克风 → 远端录音应用 | 关闭 | 首次启用需本机录音权限；PCM / 16 kHz / 16-bit / 单声道，远端需允许 shell 音频路由 |

两个开关独立，可同时开启，也能在远控设置中即时调整。远端声音通过官方 scrcpy `output` 音源采集，转发时远端扬声器停止播放。本机使用媒体音量，声音小时也检查远端媒体音量。

麦克风使用临时远端服务替代普通应用的录音输入，无需在远端安装 APK，也无需新网络端口。厂商系统可能限制此能力；失败会提示，视频可以继续。连接前拒绝录音权限可关闭麦克风继续连接；连接期间拒绝权限不会中断视频。仅观看不转发麦克风，关闭开关或结束会话会停止录音并撤销音频路由。

## 远端方向与保持唤醒

「同步远端屏幕方向」默认开启，本机横竖屏变化会明确设置远端方向，并临时关闭远端自动旋转。远端应用锁定方向时仍受应用限制。关闭同步会恢复远端原设置。

半透明远控设置提供「向左旋转」「向右旋转」，每次旋转远端 90°，本机可保持竖屏观察效果。手动方向保持到下一次手动旋转，或在同步开启时本机再次旋转。同步关闭时，本机旋转不覆盖手动方向。仅观看禁用手动和同步旋转。

「保持远端唤醒」在充电时保持亮屏。关闭对应开关、正常断开或连接丢失后，远端服务负责恢复原旋转及保持唤醒设置；具体清理机制见 [架构说明](architecture.md)。

## 应用设置与数据

配置页右上角齿轮包含本机名称、语言选择、关于、当前版本、许可、项目主页和代码仓库入口。项目主页为 <https://scrcpy.oh-my-term.cn/>，由系统浏览器打开。支持跟随系统、简体中文、English；其他系统语言默认英文。远控设置内也能切换语言，不会重建视频连接。

配置与 ADB 身份密钥存储在应用私有目录，正常升级保留，应用关闭数据备份。卸载或清除数据会丢失配置与密钥，之后需重新授权。包名与数据格式见 [配置与数据](configuration.md)。

「设置 → 关于」还提供隐私政策的直接入口，使用系统浏览器打开；同一地址用于 Google Play 的隐私政策字段。
