# 1.1.1：组织与包名迁移

## 变化

- GitHub 源码迁至 `moteng-network/scrcpy-apk`，沿用历史提交、tag 和 Release。
- Android 主包名改为 `cn.ohmyterm.scrcpy`；Java、Manifest、JNI 导出符号、测试探针与麦克风服务入口同步修改。
- 版本为 1.1.1 / versionCode 15；签名身份沿用既有证书，release 不可调试。
- 新旧包可并存，不能覆盖升级；配置和 ADB 身份不会自动迁移，需重新配置和配对。旧版下载保留。

## 实际验证

使用本任务的 Android 11 主控 AVD 和 Android 16 被控 AVD、独立 adb server：

- Release、测试 APK 与探针构建通过，34 项 JVM 测试和 release lint 通过。
- 错误配对码被加密协议拒绝；真实六位配对码、二维码配对、TLS 连接和原生视频首帧通过。
- 经典 TCP 视频与断开通过；Android 配对列表保留完整的自定义设备名。
- 在专用 root Android 16 AVD 上，从新 APK 加载 `cn.ohmyterm.scrcpy.MicServer`，启动成功、通过本会话 socket 接收 PCM，连接关闭后正常清理。
- APK 包名、版本、非调试标记和签名证书已核对；文档链接和索引检查通过。

## 验证边界

完整声音运行时测量脚本在 Android 11 主控 AVD 的音量命令预检阶段停止：系统命令无输出，未进入声学测量。普通 shell 身份的 Android 16 麦克风探针也遇到输入设备不可用；root AVD 的入口验证另行通过。这些结果不能写成所有音频组合已重新验证。

本轮只改变命名与仓库归属，没有修改音频实现；未重做真机 USB 插线、实体摄像头扫码、真机扬声器 / 麦克风或所有 ABI 的设备验收。二维码验证使用实际 QR 图像解码与 Android 系统配对服务。
