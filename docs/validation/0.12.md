# 0.12 验证记录

配置页右上角的语言快捷键改为齿轮设置按钮。设置弹窗沿用应用的深色圆角样式，包含语言选择、应用简介、构建版本号、GPL-3.0 许可说明和代码仓库入口。版本来自构建配置，仓库入口通过浏览器打开项目地址。语言选择仍支持跟随系统、简体中文和 English。

## 自动化验证

JDK 11、Android SDK 31 离线构建通过，30 项 JVM 测试通过，app lint 无错误。

两个专用 Android 14 AVD 上运行 `--phase app-settings`，检查：

- 配置页通过设置按钮进入弹窗；关于、当前构建版本、许可及仓库地址正确。
- 设置中切换语言即时更新弹窗和配置页；未保存的主机名和暂时无效的数字输入保留，手动语言选择在进程重启后生效。
- USB 连接方式在切换语言后保留，跟随系统及中英文选项均可使用。
- 左右横屏时内容可滚动，底部完成按钮始终可用；仓库入口发出包含准确项目 URL 的浏览器打开请求，系统返回键关闭设置弹窗。

另以 `--phase language-live` 检查现有远控设置中的语言选择：切换语言时视频会话保持，虚拟键盘和断开确认同步更新。

本次只调整界面、语言入口和项目信息；USB 功能此前已由用户实机验收通过，见 [0.11 验证记录](0.11.md)。
