# 1.1.2：设置中的项目主页

「设置 → 关于」新增项目主页链接 <https://scrcpy.oh-my-term.cn/>，与代码仓库采用相同的卡片样式，支持中英文。通过系统浏览器打开；无浏览器时显示提示。版本为 1.1.2 / versionCode 16，包名与签名保持不变，可覆盖 1.1.1。

使用本任务的 Android 11 主控 AVD 验证：

- Release 构建、release lint 与文档检查通过。
- 中英文界面分别检查竖屏、左横屏、右横屏；主页与代码仓库可滚动到，位于固定「完成」按钮之上。
- 点击主页入口，由系统发出 `ACTION_VIEW`，网址为 `https://scrcpy.oh-my-term.cn/`。
- 项目网站的中文、英文、隐私与支持页已检查 HTTPS，旧地址跳转到新域名。

本轮只增加外部链接入口，没有改 ADB、音视频或输入协议；没有重复配对、真机 USB 或声音测量。
