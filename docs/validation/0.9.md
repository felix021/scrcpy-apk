# 0.9 验证记录

对照 oh-my-term 的 QWERTY 布局，将完整键盘调整为六行：两行较扁、较宽的控制键，三行字母键，以及包含空格和回车的底行。Shift 和退格位于第三个字母行两侧，取消独立数字行及单独的 Caps 按键。只提供 QWERTY 字母布局，数字和其他符号通过上滑或「123」面板输入。

字母键上方显示对应数字/符号，上滑输入该字符，下滑输入大写字母。句点上滑输入逗号。滑动只在松手时发送一次，横向拖动和取消不发送字符，也不会额外触发原键。长按 Shift 可锁定大写；上滑始终发送标出的字符，不受 Shift 锁定影响。Fn + Q–P 对应 F1–F10，F11/F12 保留在控制区。

## 构建

JDK 11、Android SDK 31，离线构建 APK 和验证应用，运行 18 项 JVM 测试及 app lint，全部通过。新增测试检查所有 QWERTY 上滑映射都有正确的物理按键编码。

## 双 AVD 验证

使用两个专用 Android 14 AVD，经实际 ADB TCP 连接；一台运行客户端，一台运行原生输入框验证应用。测试日志和截图保存在仓库外，使用 `scripts/verify-avd.py --phase keyboard`。

测试读取远端输入框和实际按键事件，检查六行结构、控制键相对尺寸、退格和回车所在行，以及上下滑输入、Shift 锁定时的上滑和横向拖动取消。

`--phase keyboard` 通过以下实际输入检查：

- 点击输入字母、Shift 一次性大写及长按锁定、Ctrl+A 一次性与锁定组合、Alt+方向键。
- 上滑 Q/A/Z/句点分别输入 `1`、`-`、`@`、`,`，下滑 Q 输入 `Q`；锁定 Shift 后上滑 Q 仍输入 `1`。
- 横向拖动字母键不插入字符；Shift 符号、Fn 的 F1/F11 和 Home 按键编码正确。
- 中文与 6 KB 文本发送、长按退格连续删除及松手停止。
- 横屏六行及控制键尺寸保持正确，键盘位于视频右侧，无需重连即可继续输入；两端横屏时画面比例和侧栏正常。
- 隐藏虚拟导航键后仍可使用完整键盘和远端边缘动作。

`--phase keyboard-layout` 在最终安装包上通过竖屏和横屏检查：底行回车与空格、上滑数字/符号、下滑大写在远端输入框产生预期文本，横屏继续使用同一视频连接。
