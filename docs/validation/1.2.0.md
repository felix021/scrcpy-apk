# 1.2.0：Google Play 首发准备

[验证索引](README.md) · [Google Play 指南](../google-play.md)

本轮把主应用更新到 target / compile SDK 36，使用 AGP 8.10.1、Gradle 8.14.3、JDK 21，保留最低 Android 8.0。远控注册 Android 13+ 系统返回回调，配置页在 Android 15+ 应用系统栏和屏幕开孔 Insets。Play 构建使用独立上传密钥；GitHub release 保留原证书。

## 构建与静态检查

- `:app:bundlePlay :app:assemblePlay :app:assembleRelease` 成功；版本 1.2.0 / 17，包名 `cn.ohmyterm.scrcpy`。
- 34 项 Play JVM 测试通过，`lintPlay` 无错误；验证探针可构建。
- `bundletool validate` 通过，AAB 签名可校验；没有 Play 环境凭据时，`validatePlaySigning` 明确失败。
- GitHub release APK 的证书指纹与原发行证书一致；Play APK / instrumentation 使用匹配的独立上传证书。
- AAB 为 `PAGE_ALIGNMENT_16K`；最终 APK 四种 ABI 的原生库 ZIP 偏移为 16 KB 对齐，arm64-v8a / x86_64 的 ELF LOAD 对齐为 `0x4000`。

## Android 16 实际连接

使用两台明确归属本任务的 Android 16 x86_64 AVD，主控安装非调试 Play APK 与同证书的测试 APK，目标为已授权、启用无线调试的可调试 AVD。所有命令明确指定设备。

- 错误六位码收到真实配对协议的校验拒绝。
- 正确六位码与实际界面二维码均完成系统配对，TLS 视频显示首帧，Android 保存完整客户端名称。
- 两种配对之后均通过本机系统 Back 让远端从 Settings 首页回到桌面，连接保持，再从运行时设置确认断开。
- 传统 TCP ADB 显示视频首帧并正常断开。
- `app-settings` 专项通过：中英文 / 跟随系统、未保存字段、重启持久化、左右横屏、设置弹窗底部操作、仓库浏览器入口和系统 Back。
- 从实际界面生成配置页、远控、六行键盘和运行时设置截图；原始素材留在仓库外，二维码秘密不用于商店图片。

首次全屏提示可能遮住界面的无障碍树，测试只关闭 System UI 的首次提示。返回测试在配对结束后先让远端回桌面，再打开 Settings，避免配对广播及后台已有设置任务改变返回起点。测试辅助桥接只存在于 instrumentation，生产应用不包含这些入口。

## 旧系统启动

Android 11 / API 30 专用 AVD 使用原证书的 release APK 覆盖安装成功，原有配置仍可显示；MainActivity 正常启动，配置页系统 Back 返回桌面。此项验证新系统 API 的版本保护，不把它扩写为 Android 11 的完整远控专项。

## 边界与发布状态

16 KB 检查是静态校验，没有以 16 KB 页设备运行；x86_64 模拟器不能替代 ARM 实机或 USB Host 链路。此次没有重新测量声音 / 麦克风或重跑全部历史专项；既有实机验收与本轮结果分开记录。

中英文商店文案、审核步骤、图标和宣传图源位于 `play/`。当前只完成首发准备，没有据此声称已上传、提审或在售；首次 Console 建档、首个 AAB、付费价格、内容声明与实际审核状态仍需核对。
