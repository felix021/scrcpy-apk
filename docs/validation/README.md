## 新记录如何写

文件命名为 `<version>.md`，加入上表。报告至少包含：

1. 本次实现或行为变化，不必重复全部产品介绍。
2. 实际环境：系统版本、设备类型、连接方式；去掉私人地址、序列号与凭据。
3. 构建检查与实际运行的验证阶段、退出结果；重要行为给出截图观察或真实事件 / 音频测量结论。
4. 证据边界：哪些使用模拟协议、AVD、实机，哪些未运行或中断，以及补跑范围。
5. 用户反馈与开发侧实测分开记录；不补写未提供的型号、场景或结果。

APK、截图、日志、SDK 本地配置和身份密钥保存在 Git 之外。记录可引用对应源码提交和 APK 哈希，但不写只在个人机器存在的绝对路径。纯文档修改无需新增版本记录。
