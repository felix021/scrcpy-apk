# scrcpy APK

在 Android 上查看并控制另一台 Android 设备。通过设备 IP 或主机名连接 ADB TCP，无需电脑中转视频，也不需要额外开放投屏端口。

- 紧凑配置界面、底部固定连接按钮、实时视频、单指和多指触控。
- 远控页隐藏本机系统栏，顶部留出完整状态栏高度的空白，竖屏底部同一行放置连接状态、返回 / Home / 最近任务三键，以及键盘和断开图标按钮，并避开系统安全区。横屏时状态移到左侧，按钮在右侧竖排，避开圆角与摄像头，取消底部工具栏占用。连接状态允许换行并自动缩小，三键独立对齐屏幕中线。手动断开需确认，取消后继续远控。
- 从远控画面四边向内滑动：左右边返回、底边回桌面、顶边打开控制中心。也可从画面旁的黑边滑入；不依赖远端使用手势导航还是三键导航。物理屏幕的系统保留区域仍由本机处理。
- 「展示虚拟按键」默认勾选，取消后可通过边缘手势操作；完整键盘仍可单独展开。
- 完整虚拟键盘参考 oh-my-term 的双行控制区，上行放置 Esc / Ctrl / Home / ↑ / End / PgUp 等键，下行放置 Tab / Alt / ← / ↓ / → / PgDn 等键。另有字母、数字、符号、Shift、Caps Lock 和 Fn 层。支持中文文字发送与主动粘贴；横屏时键盘放在画面右侧。
- 保存配置、文字输入、切换及确认弹窗使用统一深色圆角样式，输入错误直接显示在弹框内；键盘弹出时底部操作区保持可见。
- 省流、均衡、高清三档快捷参数；最长边、码率、帧率均可修改；视频编码通过下拉菜单选择 H.264 / H.265。
- 保存多台主机的完整连接配置，包含名称、地址、端口、画面参数和全部控制开关；深色配置弹窗显示名称和地址，选中后高亮，确认后切换；删除需要再次确认。支持同名更新并记住上次使用的配置，兼容旧版已保存数据。
- 本机横竖屏切换时，明确设置远端方向，并在会话期间临时关闭远端自动旋转；会话结束或连接丢失时恢复原来的旋转设置。远端应用自身锁定方向时仍遵守应用限制。仅观看模式不改变远端方向。
- 仅观看模式、充电时保持远端唤醒。切到后台或点击断开后结束连接。
- 两个独立的声音开关：默认开启「播放远端声音」，默认关闭「转发本机麦克风」，可随主机配置保存。前者把远端系统声音传回本机；后者将本机麦克风作为远端应用的录音输入，仅在开启后申请本机录音权限。两者可同时使用。
- 使用固定版本的官方 scrcpy 5.0.1 server。

## 使用

1. 客户端需要 Android 8.0+，远端需要支持所选编码的 Android 设备。
2. 保证客户端能够访问远端 IP 和 ADB 端口，例如两端在同一局域网中。
3. 远端开启 ADB TCP，例如 `adb tcpip 5555`。支持传统 ADB TCP 授权，暂不支持 Android 无线调试的配对码/TLS 模式。
4. 输入远端 IP 与端口，选择或修改参数，点击连接。可用地址上方的「保存配置」为每台主机命名，以后通过「切换配置」选中主机并确认，再点底部连接按钮。修改后再次保存，同名配置会更新；画质快捷档不会改动配置名称。首次连接需要在远端确认调试授权，可以勾选始终允许。
5. 直接触控远控画面；本机返回键和返回手势发送到远端。使用断开图标并确认以结束会话。键盘图标可展开完整虚拟键盘。

键盘的 Ctrl / Alt / Shift / Fn 点按后对下一个键生效，长按可锁定，再次点按取消；收起键盘、旋转屏幕或断开时会清除修饰状态。Fn + 数字行提供 F1–F10，右上方提供 F11 / F12；Home / End / PgUp / PgDn 在双行控制区直接使用，Fn + Esc 是 Menu，Fn + Tab 是 Insert。键盘中的 Home 是编辑导航键，底部房子图标用于返回 Android 桌面。长按退格或方向键可连续操作。

普通应用无法完全关闭本机强制的系统手势。远控页使用沉浸模式，顶部保留状态栏高度的缓冲，底部避开系统保留区；从远控画面边缘向内滑动可操作远端。从物理屏幕最顶端或最底端滑动，仍可能唤出本机系统栏或触发本机 Home。

「文字」弹窗使用本机输入法输入任意文字，再发送到远端；「粘贴」只在主动点击时读取本机剪贴板。这两项通过远端剪贴板粘贴，单次最多 64 KiB UTF-8，会覆盖远端剪贴板内容。

声音播放使用 AAC / 48 kHz / 双声道，远端需 Android 11+；Android 11 连接时需保持屏幕解锁。通过官方 scrcpy 的 `output` 音源采集，转发时远端扬声器停止播放。可使用本机媒体音量调节；声音较小时也请提高远端媒体音量。

麦克风转发使用 16 kHz / 16-bit / 单声道，适合语音输入。远端通过现有 ADB 通道临时启动音频服务，利用系统音频路由替代普通录音应用的麦克风输入，无需安装远端 APK，也不需要额外网络端口。仅观看模式不启用麦克风转发。远端系统需允许 ADB shell 注册录音音频路由；厂商限制可能导致此能力不可用，届时界面会提示，视频仍可继续使用。会话结束时停止本机录音并撤销远端路由。首次开启需要授予本机录音权限，拒绝后可关闭麦克风开关继续连接。

ADB 身份密钥保存在应用私有目录，正常重启和升级保留。应用不备份密钥。卸载或清除数据后，需要重新授权。

## 可选：跨网络连接

如果两台设备不在同一局域网，可以先使用 EasyTier、Tailscale 等 SDN（软件定义网络）工具建立可互访的网络，再填写远端的组网 IP。客户端只需要能访问远端的 ADB TCP 端口。

## 构建

需要 JDK 11、Android SDK 31、网络可访问 Google Maven / Maven Central / GitHub。

```bash
printf 'sdk.dir=/path/to/android-sdk\n' > local.properties
JAVA_HOME=/path/to/jdk-11 ./gradlew :app:assembleDebug :app:testDebugUnitTest
```

`prepareServer` 首次构建下载官方 server 到 `app/build/generated/server/` 并校验 SHA-256。APK 在 `app/build/outputs/apk/debug/app-debug.apk`，使用本机标准 debug 签名。编译产物、server 二进制、SDK 本地配置、密钥和测试截图均不提交。

## 端到端验收

验收脚本会在指定 AVD 安装客户端，在指定远端安装一次性验证应用，以确认触控、按键和文字的实际接收结果，结束后卸载验证应用。远端需已授权本机 adb，首次客户端授权仍需要在远端确认。

```bash
./gradlew :app:assembleDebug :validation:probe:assembleDebug
python3 scripts/verify-avd.py \
  --client <avd-serial> --target <target-adb-serial> \
  --host <target-ip> --port 5555 \
  --output /path/outside/repository
```

脚本适配专用 1080×2340 AVD，覆盖配置保存与进程重启恢复、真实视频、触控、虚拟键、客户端旋转、H.265、仅观看、参数校验和后台断开。结果和截图写入 `--output`，不会进入 Git。设备中断后，可用 `--phase lifecycle` 单独补跑后台断开与触点释放、取消后重连、远端进程退出；请为每次运行使用独立输出目录。保存与文字输入弹窗、键盘遮挡、编码菜单和导航居中专项用 `--phase dialogs`，文字输入可用 `--phase text-dialogs` 单独检查，见 [0.6 验证记录](docs/VALIDATION-0.6.md)。新图标、配置弹窗的选择/取消/二次删除确认和图标断开按钮专项用 `--phase appearance`，见 [0.5 验证记录](docs/VALIDATION-0.5.md)。多主机保存、切换和顶部留白专项用 `--phase configs`，见 [0.4 验证记录](docs/VALIDATION-0.4.md)。配置页和手势专项可用 `--phase ui` 运行；三键布局、四边动作、完整键盘和横屏专项用 `--phase controls`，结果见 [0.3 验证记录](docs/VALIDATION-0.3.md)。首次全屏提示需要确认。使用 `scripts/start-avd.sh <avd-name> <console-port>` 可避免 AVD 继承宿主机代理环境变量。双向声音、四种开关组合及录音权限专项用 `--phase audio`，使用两种测试音分别测量远端真实录音和本机真实输出。自动旋转、断开及强制结束后的设置恢复专项用 `--phase rotation`。双行控制键、左右横屏侧栏及中置摄像头避让专项用 `--phase landscape`；完整键盘输入专项用 `--phase keyboard`，见 [0.7 验证记录](docs/VALIDATION-0.7.md)。ADB 收包、控制消息和关闭竞争另有 JVM 回归测试。
